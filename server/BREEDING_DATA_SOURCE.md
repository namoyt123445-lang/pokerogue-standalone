# Breeding metadata

National species 1–1025, egg groups, evolution roots, genders, and legendary/mythical flags derived from [PokeAPI](https://github.com/PokeAPI/pokeapi/tree/f38eb24b70f8462976154f534e79bf2bdd7af847/data/v2/csv) (BSD-3-Clause project). Pinned source commit: `f38eb24b70f8462976154f534e79bf2bdd7af847`.

The generated catalog is checked in; ordinary builds do not download data. Regional/custom species outside the catalog are explicitly unavailable in this first breeding release. No game art is downloaded by this script.
